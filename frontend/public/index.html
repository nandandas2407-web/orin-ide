Token Usage Warning

Multi-agent collaboration routes multiple prompts through free OpenRouter models. Each agent call consumes tokens from your free-tier limit (typically 60 requests/min, ~200k tokens/day). A full pipeline of 4 agents may use 10k–50k tokens per task.

You can configure which free models each agent uses in the gear icon (top-right of the agents panel). If a model is rate-limited or down, agents auto-fallback to another free model.

API Usage Warning

AI Agent mode can cause heavy usage of your API keys.

Agents run multiple LLM calls autonomously — creating files, running terminal commands, and iterating on code without asking for confirmation each step. This may result in significant token consumption and API costs.

Only proceed if you understand the risks and have set usage limits with your provider.
